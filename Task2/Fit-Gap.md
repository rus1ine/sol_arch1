# Системы
## ИС «Алмазы»
### Существующие функции
Планирование работ

Присвоение идентификаторов и подготовка ведомостей.
### Недостающие функции
Отбор алмазов для цифрового аукциона
### Коментарий
Нет критериев для описания алмазов, нет инструментов загрузки и отображения этих данных

## ИС «Аукцион»
### Существующие функции
Проведение аукциона
### Недостающие функции
Публикация данных "цифровой алмаз" для клиентов

Оценка стартовой цены алмаза
### Коментарий
Необходимы инструменты для хранения, отображения и доступа клиентов к данным о цифровых алмазах

## ИС «Логистика»
### Существующие функции
Перевозка алмазов покупателям
### Недостающие функции
отправка алмазов в лабораторию и возврат в офис после оцифровки

Расчет стоимости доставки
### Коментарий
Добавляется новый маршрут перевозки алмазов офис - лаборатория - офис

## ИС «Бухгалтерия»
### Существующие функции
Актирование и оплата услуг компаний-перевозчиков, ведение контрактов
### Недостающие функции
Актирование и оплата услуг лаборатории
### Коментарий
Добавляется новый контрагент - Лаборатория





# Интеграции
